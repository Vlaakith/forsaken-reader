# Forsaken Reader

**⚠️ Имя ребёнка не писать в этом файле — он уходит в публичный репозиторий.**

Сайт для ребёнка (11 лет) для тренировки чтения на английском и изучения новых слов.

## Ежедневный процесс

1. **Обратная связь** — обсудить, что понравилось/не понравилось вчера
2. **Выбор тем** — 4-5 историй на день
3. **Написание** — создать JSON-файлы в `stories/`
4. **Обновление index.html** — новые истории в `newStoryFiles`, вчерашние переносим в `archiveStoryFiles`
5. **Пуш** — закоммитить и запушить

## Формат историй

Истории хранятся в `stories/*.json`:

```json
{
  "id": "story-id",
  "title": "Story Title",
  "icon": "🎭",
  "paragraphs": [
    [
      { "text": "Simple word" },
      { "text": "word", "ru": "перевод", "ex": "Example phrase — Пример фразы" }
    ]
  ]
}
```

- `text` — слово или фраза на английском
- `ru` — перевод на русский (опционально, для новых/сложных слов)
- `ex` — пример использования с переводом (опционально)

**⚠️ Не использовать кавычки в `ru` и `ex`!** Они ломают HTML-атрибуты. Вместо `"Spooky Scary Skeletons"` писать просто `Spooky Scary Skeletons`.

## Русские тексты (русский + корейский)

Ребёнок забывает русский, а корейский стал основным. Каждый день — один текст:
- Текст на **русском** языке
- Переводы под словами на **корейский**
- Объём: ~половина от английского (4-5 абзацев)
- Тематика: русские сказки, история России, культура

Формат тот же, просто `ru` содержит корейский перевод:
```json
{ "text": "ведьма", "ru": "마녀", "ex": "Злая ведьма — 사악한 마녀" }
```

## Формат квиза со скрытыми ответами

Чтобы ответы не были сразу видны, используем 👆 как кликабельный элемент:

```json
[
  { "text": "1." },
  { "text": "Вопрос здесь?" }
],
[
  { "text": "👆", "ru": "TRUE! ✓", "ex": "Объяснение ответа" }
]
```

Ребёнок читает вопрос → думает → отвечает вслух → тапает на 👆 → проверяет себя.

Пример: 29-c00lkidd-quiz.json

## Формат головоломки "Найди правильный"

Визуальная головоломка — найти один правильный вариант среди похожих обманок:

```json
[
  { "text": "1X1X1X1", "ru": "Nope!", "ex": "These are CAPITAL X letters" },
  { "text": "1x1x1x1", "ru": "YES! ✓", "ex": "You found the real one!" },
  { "text": "1xlxlxl", "ru": "Nope!", "ex": "Those are lowercase L, not 1" }
]
```

Виды обманок (должны быть визуально отличимы!):
- Заглавные буквы (X вместо x)
- Буква l вместо 1, или I вместо 1
- Знак умножения × вместо x
- Pipe | вместо 1
- Лишние/недостающие символы

**⚠️ НЕ использовать кириллические буквы** (х вместо x) — их невозможно отличить визуально, это нечестно.

Пример: 32-find-1x1x1x1.json

## Формат аудио-квиза

Звуковые кнопки для интерактивных квизов. Звуки хранятся в `sounds/`.

```json
{ "text": "🔊 Play", "audio": "sounds/oof.mp3", "ru": "Roblox!", "ex": "The classic death sound" }
```

- `audio` — путь к звуковому файлу
- `text` — текст на кнопке (обычно "🔊 Play" или просто "🔊")
- `ru` и `ex` — ответ, появляется в tooltip после нажатия

Кнопки отображаются фиолетовыми, после прослушивания становятся зелёными.

Источники звуков:
- [Internet Archive](https://archive.org) — для классических звуков
- [Myinstants](https://www.myinstants.com) — большая коллекция мемных звуков
- Формат: MP3

Пример: 35-sound-quiz.json

## Идеи геймификации (на будущее)

### Неожиданный язык перевода
Обычно: английский → русский, русский → корейский.
Но иногда (максимум одно слово в день!) перевод на неожиданном языке:
- Английское слово → корейский вместо русского
- Русское слово → английский вместо корейского

Это редкое событие, на которое можно "охотиться". Не случайные языки типа суахили — только те, которые ребёнок знает и может прочитать.

### Звёздочка на слове
Одно слово в дне помечено звёздочкой — особенное. Создаёт азарт открывать переводы, искать "то самое" слово.
